# HALO Precision Diagnostics

> HALO Precision Diagnostics (HALO Dx) is a Menlo Park, California precision-diagnostics company
> that acquires community imaging centers and rebuilds them as "Imaging Center 2.0" diagnostic
> hubs, combining advanced imaging, genomics and biomarker testing under one roof for early
> detection of cancer, cardiovascular disease and dementia. It is a clinical services company,
> not a software vendor: it publishes no public API, no developer program, and no
> machine-readable API contract.

## API surface

- **No public API.** There is no developer portal, API reference, OpenAPI/AsyncAPI/GraphQL
  contract, SDK, CLI, webhook catalog, MCP server or A2A agent card on any halodx.com host.
- Probed 2026-08-22 and 404: `/openapi.json`, `/swagger.json`, `/api-docs`, `/graphql`,
  `/llms.txt`, `/.well-known/security.txt`, `/.well-known/api-catalog`,
  `/.well-known/agent-card.json`, `/.well-known/agent.json`, `/fhir/metadata`,
  `/.well-known/smart-configuration` — on `www.halodx.com`, `api.halodx.com` and `my.halodx.com`.
- `api.halodx.com` resolves in DNS but returns a bare HTTP 404 with an empty body on every path;
  nothing is served behind it.
- `my.halodx.com` 302s to a port-8080 web application (an image/records portal), which is a
  credentialed end-user surface, not a documented API.
- The only machine-readable JSON on the marketing host is the stock WordPress core REST API at
  `https://www.halodx.com/wp-json/` (422 routes, all WordPress core and plugin namespaces —
  wp/v2, yoast/v1, elementor/v1, gf/v2). It is the CMS's default output, not a HALO product API,
  and it is not registered as an API in this profile.

## Integration reality

Referring physicians integrate with HALO through vendor-operated products, not a HALO-published
interface:

- **Provider portal** — RoyalMD (order management, results, break-glass search, mobile apps).
  Access is requested through a form: https://www.halodx.com/provider-resources/
- **Enterprise image viewer** — eUnity, with a published quick-start guide (PDF).
- **EMR integration** — HALO markets "seamless EMR integrations for pushing orders and pulling
  results" as a capability delivered by those vendors; no interface specification, endpoint or
  contract is published.

## Clinical scope

- Cancer — whole-body and multiparametric MRI, PSMA-targeted PET (PYLARIFY), digital pathology,
  polygenic risk scoring, hereditary and proteomic testing.
- Prostate — mpMRI diagnosis, MRI-guided targeted biopsy, MRI-guided TULSA-PRO focal ablation,
  BPH treatment.
- Breast, lung, neuro health, and cardiac imaging (coronary CT angiography).
- Cardiovascular disease and dementia programs announced for 2026.
